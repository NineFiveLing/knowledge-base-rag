# eval-llm-scoring Specification

## Purpose

提供基于 LLM 的三维度评测能力：对评测集中每条用例运行 RAG 实验，从相关性、忠实度、可信性三个维度打分并说明差距，结果推送到 LangFuse 实验页展示。

## Requirements

### Requirement: 评测集上传与解析

评测系统 MUST 支持从 Excel 评测集（含 `问题`、`参考答案` 列）解析测试用例，并上传到 LangFuse Dataset。

#### Scenario: 从 Excel 上传评测集
- **WHEN** 提供一份含 `问题` 与 `参考答案` 两列的 Excel 评测集文件
- **THEN** 系统解析出测试用例集，上传到 LangFuse Dataset，返回 Dataset ID 与用例数

### Requirement: 逐条执行 RAG 实验

评测系统 MUST 对评测集内每一条测试用例运行一次 RAG 问答实验，并获取该回答所依据的检索上下文。

#### Scenario: 对每条用例跑 RAG
- **WHEN** 评测开始执行
- **THEN** 对每条用例的问题调用 RAG 管道，获得生成回答与本次检索到的上下文文本

### Requirement: 相关性评分

对每条用例，LLM 评判器 MUST 依据「问题 vs 回答」判断相关性：回答是否切题、是否直接覆盖问题要点，输出 0~1 分数与评分理由。

#### Scenario: 回答切题
- **WHEN** 生成回答直接回应了问题核心
- **THEN** 相关性维度得到较高分数（接近 1），理由说明切题之处

#### Scenario: 回答偏题
- **WHEN** 生成回答未针对问题或覆盖要点不足
- **THEN** 相关性维度得到较低分数，理由列出遗漏或偏离的要点

### Requirement: 忠实度评分

对每条用例，LLM 评判器 MUST 依据「检索上下文 vs 回答」判断忠实度：回答的论断是否都能在检索上下文中找到依据、有无编造，输出 0~1 分数与评分理由。

#### Scenario: 回答有据可查
- **WHEN** 生成回答的论断在检索上下文中均有出处
- **THEN** 忠实度维度得到较高分数

#### Scenario: 回答编造内容
- **WHEN** 生成回答包含检索上下文中不存在的论断
- **THEN** 忠实度维度得到较低分数，理由指出编造的具体内容

### Requirement: 可信性评分

对每条用例，LLM 评判器 MUST 依据「标准答案 vs 回答」判断可信性：回答与标准答案的关键事实点是否吻合、是否可验证，输出 0~1 分数、评分理由与遗漏的关键事实点列表。

#### Scenario: 回答与标准答案事实吻合
- **WHEN** 生成回答覆盖了标准答案的关键事实点且无矛盾
- **THEN** 可信性维度得到较高分数

#### Scenario: 回答遗漏或错误
- **WHEN** 生成回答遗漏了标准答案中的关键事实点或与之矛盾
- **THEN** 可信性维度得到较低分数，理由和遗漏点列表明确指出缺失或错误之处

### Requirement: 结果推送 LangFuse 实验页

评测产生的三维度分数 MUST 关联到本次实验 run，并推送到 LangFuse：每个维度一条 Score（0~1 数值），评分理由与遗漏点随 Score 一并可查。

#### Scenario: 推送分数到实验 run
- **WHEN** 一条用例完成评分
- **THEN** 该用例生成回答关联的 trace 被关联为实验 run 项，三维度分数以 Score 形式推送到 LangFuse 实验页，理由与遗漏点在 Score 中可见

### Requirement: 单条用例失败不中断

评测过程中单条用例的 RAG 执行或评分失败时，系统 MUST 记录该条失败并继续执行剩余用例。

#### Scenario: RAG 执行失败
- **WHEN** 某条用例的 RAG 执行抛出异常
- **THEN** 该条记录为失败，后续用例继续执行，评测结果包含失败标记

#### Scenario: 评分输出非法
- **WHEN** LLM 评分返回无法解析或非法的输出
- **THEN** 该条评分标记为失败，不影响其他用例的评分
